CloudGuard

云守护

为群组服提供一致的安全管理体验。封禁、禁言和警告实时同步，异常行为会形成可追溯的风险事件。

开始安装 下载 v1.7.0
当前版本v1.7.0
支持服务端Paper / Purpur
Minecraft1.20 - 1.21
作者MoutainSeaL
01 / Features

核心功能

集中处理处罚、审计和风险提醒。

01

统一处罚

封禁、禁言与警告在全服同步。

02

行为审计

记录管理员操作和高风险事件。

03

风险提醒

对刷屏、异常移动与批量操作预警。

04

WebHook

将关键事件推送到外部管理频道。

02 / Installation

安装方法

群组服推荐同时部署 CloudCore。

1

下载插件

下载最新 CloudGuard 文件。

2

部署至子服

将文件放入每个子服的 plugins/。

3

检查同步

执行 /guard inspect <玩家> 测试。

操作审计

生产环境建议使用 MySQL，并配置至少 90 天审计保留期。

03 / Commands

命令与权限

处罚命令默认仅管理员可用。

命令功能权限
/guard inspect <玩家>查看玩家风险与处罚记录cloudguard.inspect
/guard warn <玩家> <原因>警告指定玩家cloudguard.moderate
/guard mute <玩家> <时长>跨服禁言玩家cloudguard.moderate
/guard reload重新加载安全策略cloudguard.admin
04 / Configuration

配置示例

配置位于 plugins/CloudGuard/config.yml。

config.yml
guard:
  sync-punishments: true
  audit-days: 90
  alert-threshold: MEDIUM

webhook:
  enabled: false
  url: ""

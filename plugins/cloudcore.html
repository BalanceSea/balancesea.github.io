CloudCore

云核心

系列插件的共同底座。CloudCore 统一管理语言、数据库连接、玩家缓存和服务发现，让其他模块保持轻量并能独立升级。

开始安装 下载 v2.3.0
当前版本v2.3.0
支持服务端Paper / Purpur
Minecraft1.20 - 1.21
作者MoutainSeaL
01 / Features

核心功能

为云插件系列提供稳定、统一的基础服务。

01

统一配置

集中维护语言、数据库与服务器标识。

02

跨服通信

基于 Redis 的低延迟消息通道。

03

模块热载

安全重载系列模块，无需整服重启。

04

状态诊断

内置健康检查和依赖状态报告。

02 / Installation

安装方法

在继续之前，请确认服务端使用 Java 21。

1

下载 CloudCore

从 Releases 下载最新 JAR 文件。

2

放入插件目录

移动至服务端 plugins/ 目录。

3

启动并检查

执行 /cloud status 检查模块状态。

建议首先安装

群组服应先安装 CloudCore，再部署其他云插件模块。

03 / Commands

命令与权限

核心管理命令默认仅管理员可用。

命令功能权限
/cloud status查看系列模块与服务状态cloudcore.status
/cloud reload重新加载核心与模块配置cloudcore.admin
/cloud debug生成诊断报告cloudcore.admin
04 / Configuration

配置示例

配置位于 plugins/CloudCore/config.yml。

config.yml
server-id: lobby-01
language: zh_CN

storage:
  type: SQLITE

redis:
  enabled: false
  host: 127.0.0.1

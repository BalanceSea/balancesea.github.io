CloudQuest

云任务

用于构建新手引导、每日目标和长期任务线。任务条件与奖励均可配置，并在不同子服间保持玩家进度一致。

开始安装 下载 v1.3.4
当前版本v1.3.4
支持服务端Paper / Purpur
Minecraft1.20 - 1.21
作者MoutainSeaL
01 / Features

核心功能

从新手引导到长期玩法目标。

01

任务链

支持前置任务、分支和隐藏目标。

02

每日轮换

按权重自动生成每日与每周任务。

03

丰富条件

击杀、收集、位置、经济等条件。

04

奖励编排

命令、物品、经验与自定义脚本奖励。

02 / Installation

安装方法

任务文件使用 YAML，支持按文件夹组织。

1

安装插件

将 CloudQuest 放入 plugins/。

2

添加任务

在 quests/ 中创建任务定义。

3

重新加载

执行 /quest admin reload。

进度同步

搭配 CloudCore 可让玩家在不同子服继续同一任务。

03 / Commands

命令与权限

玩家可通过任务手册管理进度。

命令功能权限
/quest打开任务手册cloudquest.use
/quest track <任务>追踪指定任务cloudquest.use
/quest abandon <任务>放弃可重复任务cloudquest.use
/quest admin reload重新加载任务定义cloudquest.admin
04 / Configuration

配置示例

配置位于 plugins/CloudQuest/config.yml。

config.yml
quests:
  daily-count: 3
  weekly-count: 2
  auto-claim: false

progress:
  sync: true
  flush-seconds: 30

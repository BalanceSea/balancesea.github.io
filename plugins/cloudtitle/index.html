CloudTitle

云称号

面向 Paper 1.21.11 生存服、会员服和群组服的完整称号系统。玩家通过仓库、商城与称号工坊管理身份展示，管理员可以组合金币、点券、权限、物品和 PAPI 数值条件，并为称号附加原版药水 Buff。

01 / Features

核心功能与边界

CloudTitle 独立运行，不依赖 CloudCore；外部插件仅在启用对应领取方式时需要。

01

仓库、商城与工坊

三个独立 TrMenu 风格 GUI，支持字符布局、动态称号槽、MiniMessage、翻页、点击类型、命令动作和 0 - 5000ms 点击冷却。

02

多条件称号获取

支持 Vault 金币、PlayerPoints 点券、权限、免费领取、PAPI BigDecimal 数值比较，以及原版/CraftEngine 物品分段提交。

03

显示与原版 Buff

提供彩色、MiniMessage、纯文本、描述和 ID 变量。Buff 只清除插件记录的同等级效果，不删除其他系统后来施加的更高等级效果。

04

SQLite / MySQL 跨服

数据库 I/O 在专用异步线程执行。共享 MySQL 保存拥有状态、选择、自定义称号和提交进度；每台子服必须使用唯一 server-id。

商城获取类型

type依赖行为
moneyVault + 经济插件扣除 double 金币，数据库失败会退款。
pointsPlayerPoints价格向上取整为整数点券，数据库失败会退款。
permission权限插件可选检查 shop.permission，不扣费。
itemCraftEngine 物品才需要 CraftEngine只扫描玩家主存储栏，可多次提交；完成时原子授予称号并清除进度。
papiPlaceholderAPI所有有效数值条件均满足才领取；未展开、非数值或 PAPI 缺失均拒绝。
free无直接授予称号。
02 / Installation

安装环境与依赖

精确目标为 Paper 1.21.11、Java 21。构建产物名固定为 CloudTitle-1.0.jar，源码版本当前为 1.0-SNAPSHOT。

1

安装 JAR

将 CloudTitle-1.0.jar 放入 plugins/，不要解压或二次打包。

2

首次联网启动

Paper LibraryLoader 从 Maven Central 加载 HikariCP 6.3.0、SQLite JDBC 3.50.3.0 和 MySQL Connector/J 9.4.0。

3

选择存储并配置

单服保持 SQLite；群组服在所有节点配置同一 MySQL 和不同 server-id，然后完整重启。

依赖矩阵

依赖类型缺失时行为
Paper 1.21.11 / Java 21运行环境其他实现或版本未声明兼容，不应视为受支持。
HikariCP、SQLite JDBC、MySQL Connector/JLibraryLoader 运行库下载或数据库驱动初始化失败时插件停用。
Vault软依赖money 购买/创建返回经济服务不可用；其余功能正常。
PlayerPoints软依赖，反射接入points 购买/创建不可用；其余功能正常。
PlaceholderAPI 2.11.7+软依赖不注册 CloudTitle 变量，papi 类型称号不能领取。
CraftEngine软依赖，反射接入原版物品仍可兑换；含 CraftEngine 要求的称号拒绝提交。
03 / Commands

全部命令与权限

主命令：/cloudtitle；别名：/ct、/title、/称号。玩家数据未加载完成时相关操作会返回 loading。

命令执行者权限默认授权行为
/cloudtitle玩家cloudtitle.use所有玩家打开称号仓库第一页。
/cloudtitle shop玩家cloudtitle.use所有玩家打开商城第一页。
/cloudtitle custom玩家cloudtitle.use + 配置的 custom-title.permission默认所有玩家打开工坊；功能关闭或额外权限不足时拒绝。
/cloudtitle set <id>玩家cloudtitle.use所有玩家仅能佩戴自己拥有且仍存在定义的称号。
/cloudtitle clear玩家cloudtitle.use所有玩家清空真实选择并移除插件记录的 Buff；PAPI 显示可回退默认称号。
/cloudtitle grant <玩家> <id>玩家/控制台cloudtitle.adminOP只能发放 titles.yml 中的静态称号，支持离线玩家 UUID。
/cloudtitle revoke <玩家> <id>玩家/控制台cloudtitle.adminOP回收拥有记录、自定义称号和提交进度；若正在佩戴则清除。
/cloudtitle reload玩家/控制台cloudtitle.adminOP关闭所有插件 GUI、取消工坊输入、重载配置并重应用在线玩家 Buff。

plugin.yml 权限

权限默认用途
cloudtitle.usetrue基础玩家命令及 GUI。
cloudtitle.adminop发放、回收、重载。
cloudtitle.customtrue默认工坊权限；配置可换成其他节点。
cloudtitle.custom.bypassop默认自定义称号费用豁免。
04 / Placeholders

PlaceholderAPI 与 GUI 变量

PAPI 扩展只读取登录时异步加载的内存缓存，不会在聊天、TAB 或计分板刷新时同步访问数据库。

变量返回值默认称号回退

%cloudtitle_name%		Legacy § 颜色格式称号名是
%cloudtitle_title_minimessage%
%cloudtitle_minimessage%		原始 MiniMessage 称号名是
%cloudtitle_title_plain%
%cloudtitle_plain%		纯文本称号名是
%cloudtitle_description%纯文本描述，各行以空格连接是
%cloudtitle_selected_id%真实佩戴 ID；未佩戴返回空否
%cloudtitle_displayed_id%最终显示 ID是
%cloudtitle_owned_count%仓库称号数量不适用
缓存尚未就绪

玩家未登录、数据仍在加载或 PlaceholderAPI 未安装时不会查询数据库；变量可能返回空字符串，未知参数交由 PlaceholderAPI 按未知变量处理。

06 / Operations

数据库、性能、重载与升级

数据库结构

配置表主键保存内容
tables.playersuuidselected_title、applied_buffs、applied_server
tables.owneduuid + title_id玩家拥有称号
tables.custom-titlesidowner_uuid、name、description、created_at；自动创建 owner_uuid 索引
tables.item-progressuuid + title_id + item_key分段提交数量
重载不是数据库重连

/cloudtitle reload 会关闭全部插件 GUI、取消未完成的工坊聊天输入、重载 YAML、重新接入经济服务并重应用在线 Buff；不会重建 Hikari 数据源，也不会更换 server-id 或定时任务周期。存储、server-id 和 refresh-ticks 调度周期变更后必须重启。

性能与一致性

  • SQLite 使用单连接、单异步存储线程；MySQL 使用 HikariCP，异步线程数为连接池的一半且最少 2。
  • PAPI 查询只读缓存；GUI 与聊天监听在主线程更新 Bukkit 状态，数据库回调切回主线程。
  • MySQL 物品提交使用事务和 FOR UPDATE，避免同一进度并发超交；SQLite 依赖单线程串行。
  • 插件卸载时关闭 GUI、卸载在线玩家、等待数据库任务最多 5 秒并关闭数据源。

升级与迁移

  • 旧版默认语言前缀“云世界称号”会在精确匹配时改为“云称号”；自定义前缀不会覆盖。
  • 三个旧版默认 GUI 标题会在精确匹配时迁移为“云称号 · 仓库/商城/工坊”；自定义标题不覆盖。
  • 旧测试目录可能存在根目录 gui.yml，当前版本不读取该文件；实际 GUI 位于 gui/ 子目录。
  • 修改表名会创建空表，不自动搬迁旧数据；操作前备份数据库并自行迁移。
  • 语言文件缺失键由内置 zh_CN 提供运行时默认值，但不会自动写回所有新键。

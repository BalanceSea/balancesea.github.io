CloudChat

云聊天

清晰可控的跨服聊天方案。支持频道路由、格式占位符、私聊回复、提及提醒和可审计的内容过滤。

开始安装 下载 v2.1.1
当前版本v2.1.1
支持服务端Paper / Purpur
Minecraft1.20 - 1.21
作者MoutainSeaL
01 / Features

核心功能

管理跨服聊天、私聊和内容过滤。

01

多频道

全局、本地、交易和自定义频道。

02

跨服私聊

玩家可在不同子服间私聊与回复。

03

格式系统

兼容 PlaceholderAPI 与 MiniMessage。

04

内容治理

敏感词、刷屏限制和聊天审计。

02 / Installation

安装方法

可选安装 PlaceholderAPI 扩展聊天格式。

1

下载插件

下载最新的 CloudChat 文件。

2

放入目录

将文件放入 plugins/ 并重启。

3

测试频道

执行 /channel global 切换频道。

跨服功能

搭配 CloudCore 和 Redis 可启用跨服频道与私聊。

03 / Commands

命令与权限

聊天命令支持玩家名和频道名补全。

命令功能权限
/channel <频道>切换默认聊天频道cloudchat.channel
/msg <玩家> <消息>向玩家发送私聊cloudchat.message
/reply <消息>回复最近的私聊cloudchat.message
/chat mute <玩家>禁言指定玩家cloudchat.moderate
04 / Configuration

配置示例

配置位于 plugins/CloudChat/config.yml。

config.yml
chat:
  default-channel: global
  mention-sound: true
  cooldown-seconds: 2

filter:
  enabled: true
  action: REPLACE

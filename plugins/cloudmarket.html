CloudMarket

云市场

为服务器经济提供可靠的玩家交易市场。物品可跨子服浏览和购买，完整记录价格、税率、成交与退款过程。

开始安装 下载 v1.5.0
当前版本v1.5.0
支持服务端Paper / Purpur
Minecraft1.20 - 1.21
作者MoutainSeaL
01 / Features

核心功能

覆盖玩家上架、搜索、交易与审计全流程。

01

跨服市场

所有子服共享商品与订单状态。

02

智能搜索

按名称、材质、价格与卖家筛选。

03

价格保护

异常价格提醒和可配置交易税。

04

审计记录

完整保留上架、购买与退款日志。

02 / Installation

安装方法

需要 Vault 及兼容的经济插件。

1

准备经济系统

安装 Vault 与经济插件。

2

安装市场

将 CloudMarket 放入 plugins/。

3

测试交易

执行 /market 打开市场界面。

群组服建议

搭配 CloudCore 与 MySQL 实现跨服共享订单。

03 / Commands

命令与权限

市场交易命令支持 Tab 补全。

命令功能权限
/market打开市场主界面cloudmarket.use
/market sell <价格>上架手中的物品cloudmarket.sell
/market history查看个人交易记录cloudmarket.use
/market admin打开市场管理界面cloudmarket.admin
04 / Configuration

配置示例

配置位于 plugins/CloudMarket/config.yml。

config.yml
market:
  listing-limit: 12
  listing-days: 7
  tax-rate: 0.03

currency:
  provider: VAULT
  symbol: "$"
